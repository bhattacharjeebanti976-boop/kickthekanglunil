# KICK THE KANGLUNIL

A silly, browser-based 3D cartoon playground featuring the supplied face photo on the character.

## Run locally
Open `index.html` in a modern browser with an internet connection. The game loads Three.js from jsDelivr and fonts from Google Fonts.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `game.js`, and the `assets` folder (keep the folder structure).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Controls
- Click/tap the action buttons, or press `1`–`4`.
- Drag across the 3D stage to rotate the character.
- Sound can be toggled in the top-right; Reset clears the score.

The gameplay is intentionally cartoonish: bounces, wobble and confetti only.
